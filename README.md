# Sistema Bancário em Java

Projeto desenvolvido durante meus estudos de **Java e Programação Orientada a Objetos (POO)**, seguindo os exercícios do curso de Java.

## 📌 Sobre o projeto

O projeto simula uma conta bancária simples, permitindo cadastrar uma conta, realizar depósitos e realizar saques.

A conta possui uma taxa de **R$ 5,00 por saque**.

## 🚀 Funcionalidades

- Cadastro de número da conta
- Cadastro do titular
- Opção de depósito inicial
- Consulta dos dados da conta
- Realização de depósitos
- Realização de saques
- Aplicação automática da taxa de R$ 5,00 no saque
- Exibição do saldo atualizado

## 📚 Conceitos praticados

Neste exercício foram praticados conceitos de:

- Classes e objetos
- Encapsulamento
- Modificador `private`
- Construtores
- Sobrecarga de construtores
- Palavra-chave `this`
- Métodos
- Getters
- Estruturas condicionais
- Entrada de dados com `Scanner`
- Organização de classes em pacotes
